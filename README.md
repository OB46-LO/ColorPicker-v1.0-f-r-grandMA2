# ColorPicker-v1.0-f-r-grandMA2
Lua-Plugin für grandMA2 (Konsole und onPC): baut aus vorhandenen Groups und Color-Presets automatisch ein Color-Picker-Raster. Pro Group und Farbe ein benanntes, passend eingefärbtes Macro, sortiert in einem Layout, dazu eine Zeile „Alle“. Farbnamen deutsch und englisch. Inoffiziell, keine Verbindung zu MA Lighting.
